# Скриншоты для сдачи

Папки `before/` и `after/` созданы для доказательств до/после.

1. Для `before` откройте исходную версию из baseline-коммита `82d9f40` или исходный ZIP и снимите дефект.
2. Для `after` запустите исправленную версию и снимите тот же элемент.
3. Сделайте отдельные скриншоты ширин 320, 375, 768, 1024, 1440 и 1920 px.
4. Зафиксируйте светлую и тёмную тему, focus-visible у switch, invalid field после blur и открытый modal dialog.
5. Сохраняйте файлы PNG с говорящими именами, например `after-375-dark-switch-focus.png`.
6. Не обрезайте скриншот так, чтобы исчезали viewport, состояние или DevTools-доказательство.

Скриншоты не были сгенерированы автоматически: их нужно сделать в реальном браузере на локальном компьютере.
